# Week 2 – Measuring with the Sense HAT

## Objective

The aim of this week was to collect temperature, humidity and pressure readings using the Sense HAT, check the quality of the measurements, and save the data locally for later analysis.

## Work Completed

I created and tested the sensor reading, configuration, data validation and SQLite storage modules. The station was configured to collect one reading every five seconds, using the station ID `station01`.

I also used a separate configuration and database for simulated readings, so they would not be mixed with real sensor measurements.

## Testing and Results

The seven automated tests passed successfully. I also tested simulated sensor failures using `--fault-every 3` and confirmed that invalid temperature readings were recorded as missing values with an error message.

For the real Sense HAT, I collected **939 observations**, including **938 valid** and **1 invalid** observation. The valid-data rate was approximately **99.89%**.

The observations were saved in `data/weather.db` and exported to `data/readings.csv`.

## Problem Investigated

The first reading in one hardware test had a missing pressure value. Instead of treating it as zero, the program marked the observation as invalid and recorded the reason. Later readings returned valid pressure values.

## Measurement Limitations

The Sense HAT measures local temperature, relative humidity and pressure, but not wind speed, rainfall or air quality.

The temperature readings may be influenced by heat generated by the Raspberry Pi itself. Therefore, the displayed decimal places should not be confused with measurement accuracy.

The device was also moved to a different location during the work, which may affect comparisons between readings collected at different times.

## What I Learned

I learned how to separate real and simulated sensor data, handle missing measurements, validate observations, and use SQLite to store data without relying on a network connection.

I also learned how to use SSH and tmux to run a data collection program on the Raspberry Pi while working from my own computer.
